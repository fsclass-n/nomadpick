## 2026-10-26 (2차 수정)

### 여행사 실시간 수집 - Playwright
- `rpa/collector/browser.py`(HumanBrowser): 실제 Chrome UA·sec-ch-ua·ko-KR·Asia/Seoul, 자동화 흔적 제거, 홈 → 특가 페이지 이동, 마우스 이동·단계별 스크롤·불규칙한 대기, 2초 간격, 3회 재시도
- `rpa/collector/robots.py`: robots.txt RFC 9309 판단(4xx 제한 없음 → 모두투어 403 대응, 5xx 수집 안 함)
- `selectors.json`: 홈에서 현재 특가 기획전 주소를 찾는 정규식(discover) + 실제 페이지 셀렉터(하나투어 `div.card-wrap`, 노랑풍선 `ul.list_thum > li`) + 모두투어 `__NEXT_DATA__` JSON 필드
- 정제: 출발 기간(`11.01~12.31`)·날짜 목록(`11/10,17,9`) → `depart_date`~`depart_end`, 복수 일정(`3,4일`), 출발지 제외(`[부산] 세부` → 세부), 도시 사전 약 300개
- live 결과: 하나투어 77 · 모두투어 144 · 노랑풍선 106 = 327건(파싱 실패율 0~2.8%)
- 국토교통부 API 경로 개편 대응: `DmstcFlightNvgInfo/GetFlightOpratInfoList` → 실데이터 항공편 수집 확인
